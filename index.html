HexaPoint — ウェブ制作スタジオHexaPoint — Web Design Studio

HexaPoint（ヘキサポイント）は、中小ビジネスと個人のためのウェブ制作スタジオです。「プロのようなウェブページは、大きな予算がないと持てない」——その思い込みを変えるために生まれました。最小コストで、お客様の心をつかむ一枚を。それが私たちの約束です。HexaPoint is a web studio for small businesses and individuals. We started with one belief: a professional web page shouldn't require a big budget. Our promise is simple — build a page that wins customers, at the lowest possible cost.

六名前の意味The name

Hexa＝六、Point＝点。蜂の巣が六角形なのは、最小の材料で最大の強さを生むから。HexaPoint も同じ考えで、6つのサービスを“点”として無駄なくつなぎ、ひとつの完全な存在にします。Hexa means six, Point means a point. A honeycomb is hexagonal because it gives the most strength for the least material — HexaPoint works the same way, joining six services as six points into one complete, efficient whole.
